Confirm the bull case with core inflation ≤0.2% m/m, stable unit labor costs, 10Y below 4.4%, and positive ex-megacap revisions. ### Data-quality controls

The API exposes daily OHLC, volume and technical indicators but not full fundamentals, earnings/revisions, margins, balance sheets, official fund flows, options, insider or institutional ownership. Percentage returns are percentage points; Treasury closes are yields in percent. API 20-day volatility is not explicitly documented as annualized and is not used for allocation. MOVE is stale at 2026-07-24. Dashboard economic rows are mostly through June and are labeled accordingly; annual 2025 global rows were excluded from current calls.

Corporate-action/adjustment breaks contaminate some API YTD, 52-week, and long-moving-average fields (including SPY, IWF, XLU and XLY); these fields were quarantined. KOSPI spot/futures agreed directionally and was used only as regional stress context; other unexplained Asia anomalies were excluded. Shares-outstanding-derived ETF flows are confirmation only. No unsupported API field, false precision, or incompatible range definition is used.
